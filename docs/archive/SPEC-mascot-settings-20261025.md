# SPEC: Маскот в приложении + экран «Налаштування»

Дата: 2026-10-25. Ветка: `feat/mascot-settings`.

## Цели и границы

1. **Маскот на главной** (референс: скриншот владельца — зелёная чиби-девочка):
   - состояние `think` — в Hero-карточке, когда `state === 'unknown'` («Немає даних»),
     с облачком фразы;
   - состояние `sleep` — внизу главной, под «Моя черга», лежит со zzz и облачком;
   - **живой**: дыхание (покачивание), zzz-частицы, сердечки, облачко с фразой, тап — новая
     фраза + мягкий хаптик;
   - фразы на украинском, зависят от состояния питания (off/warning/on/allClear/unknown).
2. **Выключатель**: `mascotEnabled` в `SettingsContext` (key `mobile.mascot`, default `true`),
   тумблер на экране настроек. Когда выключен — маскот нигде не рендерится.
3. **Экран «Налаштування»** (`app/settings.tsx`, пушится из Інфо по шестерёнке):
   - Маскот: вкл/выкл;
   - Живий індикатор у шторці (`liveNotification`, дефолт false);
   - Детектор раннього світла (`earlyLightDetector`, дефолт true);
   - Застосунок: версия + кнопка «Оновлення та зміни» (openSheet) + бейдж pending;
   - Джерела та підтримка: Telegram, GitHub (перенос из Інфо).
4. **Чистка «Інфо»**: остаётся только стрічка новин; блоки «Застосунок» и
   «Джерела та підтримка» переносятся в «Налаштування»; шестерёнка в шапке Інфо.
