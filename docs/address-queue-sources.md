# Джерела «адреса → група/черга»: розвідка 18.10.2026

> Актуальніший реєстр прямих джерел, включно з Hydra API Львова/Тернополя/Закарпаття та
> PDF Рівненщини: [`osr-direct-sources.md`](osr-direct-sources.md). Цей документ лишається
> історичною розвідкою; частина висновків «Ні» вже застаріла (наприклад, Закарпаття).

Мета — з'ясувати, чи можна автоматично визначити групу за адресою **без** логіна, Turnstile/капчі
та обходу WAF. Перевірялися лише публічні сторінки/API з чесним User-Agent, не частіше одного
запиту на хвилину.

## Що це означає для застосунку

1. Автоматичний провайдер не підключений: `ADDRESS_QUEUE_PROVIDERS` порожній, закриті джерела
   не викликаються.
2. Замість тупика майстер показує:
   - до 4 найближчих відомих будинків із кнопкою «Це моя група» (локальна помітка);
   - ручний вибір групи з реального списку `/api/v1/queues`;
   - посилання на офіційний сайт оператора (або реєстр НКРЕКП, якщо адреса сайту не підтверджена).
3. Якщо офіційний сайт відкриє адресний API без логіна/капчі, достатньо додати реалізацію
   `AddressQueueProvider` з `access: 'open'` — маршрут `/addresses/resolve` підхопить її без змін.
