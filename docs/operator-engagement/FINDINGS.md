# FINDINGS — описание находок для оператора

Статус: черновик для передачи вендору. Не для публикации без согласования.
Воспроизведение намеренно не приводится: цель документа — устранение, а не повторение.
Формат: наблюдение → влияние → рекомендация.

---

## F-1. Несоразмерный контроль доступа: дорогая защита там, где она не нужна, и отсутствие защиты на персональных данных

**Наблюдение.** На публичном поддомене оператора сосуществуют методы с разным уровнем контроля:

- методы, отдающие данные абонента по одному числу (привязка к адресу, технические идентификаторы),
  отвечают **без проверки антибот-защиты**;
- методы, отдающие публичную справочную информацию (номер очереди ГПВ, почасовой график),
  **закрыты проверкой Cloudflare Turnstile** и без токена отклоняются.

Отдельно: один из публичных методов графика существует в двух вариантах — «полный» и
«по частям»; полный всегда возвращает пустую структуру, данные отдаёт только пошаговый.
Это признак неаккуратной реализации, а не защиты.

**Влияние.** Защита распределена инвертированно: барьер стоит на данных низкой чувствительности,
а персональные данные доступны дешёвыми запросами без барьера. Числовой идентификатор абонента
позволяет сопоставлять номера лицевых счетов с адресами. Для оператора это риск утечки ПД и
репутационный риск, для абонентов — риск адресного мошенничества.

**Рекомендации.**
1. Перенести антибот-проверку на метод, отдающий данные по лицевому счёту.
2. Добавить серверные лимиты по IP и сессии и защиту от перебора; полагаться только на уровень CDN
   для этого класса данных нельзя.
3. Не возвращать адрес целиком: достаточно подтверждения принадлежности или частично
   замаскированного значения.
4. Логировать и алертить аномальную частоту поиска по лицевым счетам.
5. Привести в порядок контракт API: убрать дублирующий метод, который всегда отдаёт пустой ответ.

**Как фиксировалось.** Проверка выполнялась на предоставленном/синтетическом идентификаторе, без
массовых запросов и без выгрузки чужих данных; персональные значения в отчёте не приводятся.

```
## F-N. Название

**Наблюдение.** Что видно на публичном контуре (факт, без оценок).
**Влияние.** Кому и чем это грозит; без преувеличений, с оценкой сценария.
**Рекомендация.** Что изменить; по возможности — приоритет и трудоёмкость.
**Ограничения.** Что не проверялось и почему.
```

## Служебное

- Срок ответа оператору: указать при передаче.
- Контакт для связи: указать при передаче.
- Персональные данные, попавшие в поле зрения случайно, не сохраняются, не передаются и не
  переносятся в этот файл.
