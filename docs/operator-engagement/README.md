В документе прямо сказано, что цель — «оценка практических навыков стажёра … в области обхода
систем защиты ботов для принятия решения о профессиональной пригодности», а результат — исходный
код обхода. Это не приёмочное тестирование устойчивости, а задание написать инструмент обхода.

И принципиальный момент: **Cloudflare Turnstile — чужая защита.** Владелец сайта не может дать
согласие от имени Cloudflare. Легальный путь один и он дешёвый: тестовые ключи Turnstile на стенде,
skip-правило для согласованных IP или отдельный staging-хост. Всё это включает сам владелец сайта —
и тогда вопрос обхода исчезает.
