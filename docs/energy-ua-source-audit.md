# Energy-UA: аудит каталогов и начальный парсер

Проверено 18.10.2026. Задача этой стадии — установить, какие региональные сайты видны,
какой уровень адресной иерархии они действительно отдают и можно ли извлечь очередь без
догадок. Данные не записывались в D1/PostgreSQL, приложение и Worker не менялись.

## Метод

- Главная `https://energy-ua.info/` содержит ссылки на региональные поддомены. Страницы
  статические и содержат HTML-каталог. Обычный `urllib` получил HTTP 403; Scrapling `Fetcher`
  с `stealthy_headers=True` и `impersonate="chrome"` получил HTTP 200 на всех связанных сайтах.
- Проверены 72 точки каталога из разных частей списков. На страницах с полной детализацией
  пройдены переходы `населённый пункт → улица → дом`; точная очередь прочитана только со страницы
  конкретного дома. Другие назначения записываются с отдельной областью действия: село или улица.
- На 51 точной странице дома парсер извлёк очередь в 51 случае. Это проверяет разбор разметки,
  но само по себе не доказывает правильность каждой привязки Energy-UA.
- Пять выбранных адресов Черниговщины сопоставлены с независимым snapshot PDF облэнерго от
  25.12.2025: все пять очередей совпали. Это проверка соответствия snapshot, не подтверждение
  актуальности PDF на дату аудита.
- Индекс GeoNames из `cf-worker/src/settlements-ua.json` использован только как набор известных
  контрольных топонимов. Совпадение названий не является знаменателем полноты: в нём есть
  варианты написания, неполные районы и агрегированные коды Киева.

## Техническое состояние парсера

Создан [tools/energy_ua_catalog.py](../tools/energy_ua_catalog.py). Он:

- обнаруживает связанные сайты с главной Energy-UA и явно сопоставляет хост с кодом области;
- разбирает два реальных варианта страниц: адресные цепочки `/select/...` и прямое назначение
  очереди `/grafik/<населённый пункт>` либо `/grafik/<населённый пункт>/<улица>`;
- сохраняет точные назначения дома отдельно от групп, присвоенных всему селу или улице;
- пишет JSONL с исходной ссылкой, областью действия и временем получения, с ограничением числа
  страниц; в БД ничего не пишет.

Установка и запуск описаны в docstring файла. Контрольная выборка лежит в
`.cache/energy-ua/audit-20261018-final.json`, небольшой экспорт парсера — в
`.cache/energy-ua/chernihiv-smoke.jsonl` (эти временные данные не коммитятся).

## Решение по включению данных

Energy-UA годится как источник для дальнейшего сбора, но не как единое доказательство точной
иерархии для всей страны. В Черновицкой и Харьковской выборке страницы дают только очередь
населённого пункта; на Полтавщине детализация неодинакова; сайты Ровненской и Запорожской
областей на корне показывают только одноимённые города. В Киеве домен объединяет город и область.
Перед импортом адресов нужно сопоставить реестры населённых пунктов, проверить реальные номера
домов и сверить назначение очереди с первичным источником соответствующего ОСР. Не переносить
группы уровня села/улицы в таблицу домов и не считать адрес без доказанной привязки точным.
