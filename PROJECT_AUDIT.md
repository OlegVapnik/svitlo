### Перенос в облако Cloudflare (закрывает риск «работает только пока включён ноутбук»)

* Новый раздатчик данных: `cf-worker/` — Worker без Node-зависимостей (Web Fetch + D1 + Cache API).
* Деплой одной командой `./deploy-cf.sh`, без GitHub и без CI. Скрипт сам создаёт D1-базу,
  подставляет `database_id`, накатывает схему и публикует фронтенд в Pages.
* Крон каждые 20 минут забирает график из зеркала расписания ДТЕК и новости из Telegram.
* **Остаток риска:** если ноутбук выключен — приложение не сломается, но новые данные
  зависят от крона Cloudflare, а не от локального бэкенда.

### Данные, которых раньше не было

* Поиск очереди по адресу (область → НП → улица → дом) с тремя уровнями совпадения.
* Народная привязка: `POST /api/v1/addresses/contribute`, источник `community`.
* Справочник 1853 населённых пунктов (GeoNames) с мгновенным поиском по префиксу.
* Контакты оператора и 20 улиц с. Деснянское — перенесены в облачную базу.
* Офлайн-снимок графика области: в офлайне работают **все** кнопки групп, а не одна.

### Найденные и закрытые дефекты контрактов

Белый экран приложения и «нулевая» статистика надёжности — не косметика, а расхождение
контрактов между воркером и фронтендом. Чтобы это не повторялось молча, добавлен

сравнивает структуру и обязательные поля. **Запускать после любого изменения маршрута в
`cf-worker/src/index.ts`.**

2. **Защита от падений контейнеров (`Exited 137` / `Exited 1`):**
   * В `docker/nginx.conf` прописать `resolver 127.0.0.11 valid=10s; set $upstream http://api:3001; proxy_pass$upstream;`, чтобы `nginx` не падал при перезапуске `api`[cite: 1].
   * В `docker-compose.yml` добавить `restart: unless-stopped`, `healthcheck` для `api` и убрать жёсткое переопределение переменных `.env` в `x-api-env`[cite: 1, 2].
