# Svitlo

**Графіки відключень електроенергії для всієї України.** Веб-застосунок (PWA), Android і
Telegram-бот: графік ГПВ для своєї черги, таймер до найближчого відключення, пошук черги за
адресою, режим мережі (ГПВ, ГАВ, СГАВ, ГОП) і новини операторів та «Укренерго».

[Веб-версія](https://svitlo-ua-4ze.pages.dev) · [Android APK](https://github.com/OlegVapnik/svitlo/releases/latest) · [Історія змін](CHANGELOG.md)

## Що це

Svitlo відповідає на три питання: **коли вимкнуть світло**, **скільки лишилося** і **що
відбувається в області**. Застосунок працює офлайн на останньому відомому знімку, а коли
оператор ще не опублікував графік — чесно каже «Немає даних», а не малює зелене «світло за
графіком».

Один домен і одні правила використовуються у вебі, Android, Telegram-боті та десктопному
віджеті; різняться лише платформенні можливості: у PWA — встановлення на домашній екран і кеш
браузера, в Android — локальна база, віджети й тихі OTA-оновлення, у Telegram — повідомлення
без встановлення застосунку.

## Можливості

- **Графік на добу за чергою.** Черги `1/1 … 6/2`, слоти по 30 хвилин, підписи «Світло є» /
  «Відключення», таймер до відключення і зворотний відлік до повернення.
- **Матриця черг області.** Усі 12 черг на одній шкалі: видно, хто без світла зараз і що буде
  далі. Відключення й статистика — окремими вкладками.
- **Режим мережі.** Повідомлення оператора й «Укренерго» класифікуються у ГПВ, ГАВ, СГАВ,
  ГОП/ГОЕ та локальні аварії. Банер показує лише те, що стосується вашої черги: аварійний
  режим — коли ваша черга в переліку або режим на всю область, ГОП — окремо й спокійно, бо це
  обмеження для бізнесу.
- **Пошук черги за адресою.** Населений пункт → вулиця → будинок. Довідник роздається
  статичними офлайн-паками з CDN: підказки починаються зі `startsWith`, далі `includes`, ліміт
  30; будинки читаються лише після вибору вулиці. Для кожної області поруч є пряме посилання на
  офіційну перевірку адреси без особового рахунку.
- **Збережені місця.** Дім, робота, дача — зі своєю іконкою, назвою й чергою. Кілька черг можна
  порівняти між собою.
- **Новини та аварійні повідомлення.** Офіційні Telegram-канали операторів і «Укренерго» (плюс
  RSS), категорії, фільтри «Моя область» / «Укренерго» / «Аварії», пошук по стрічці.
- **Карта відключень.** Leaflet, завантажується ліниво — лише на своїй сторінці.
- **Android без Play Маркета.** APK ставиться за посиланням і оновлюється тихо: JS-бандл
  приїздить окремо від APK, ставиться під час наступного запуску, пошкоджений архів
  відкочується на вбудований бандл і позначається `failed`, щоб не було циклу падінь. Є
  віджети з живим хронометром, плитка в шторці, статус на екрані блокування й локальні
  уведомлення.
- **Telegram-бот і Mini App.** Бот працює на вебхуку в тому самому Cloudflare Worker: показує
  графік на сьогодні й завтра, приймає область і чергу, надсилає попередження за 15 хвилин до
  відключення та повідомлення про ГАВ/СГАВ. Кнопка Mini App відкриває вебзастосунок одразу з
  потрібною областю й чергою.
- **Десктопний віджет.** Для Linux на Wayland (Niri + Noctalia Shell): капсула в статус-барі з
  живим таймером і попап «Командний центр» зі шкалою 48 сегментів, режимом мережі та плитками
  на сьогодні й завтра.
- **PWA.** Встановлення на домашній екран, офлайн-кеш, статус синхронізації й розрізнення
  «помилка мережі» / «помилка сервера».

## Як це працює

```
┌────────────────────┐   ┌────────────────────┐   ┌────────────────────┐
│  apps/web (PWA)    │   │ apps/mobile (APK)  │   │ Telegram / Noctalia│
│ React + Vite + SW  │   │ Expo + RN + Kotlin │   │ webhook / Luau     │
└─────────┬──────────┘   └─────────┬──────────┘   └─────────┬──────────┘
          │ HTTPS                  │ HTTPS                  │ HTTPS / stdin
          └───────────────┬────────┴────────────────────────┘
                          ▼
             ┌─────────────────────────────┐
             │  Svitlo API (Cloudflare)    │
             │  Worker + D1 + R2 + Cron    │
             └──────────────▲──────────────┘
                            │
      ┌─────────────────────┴─────────────────────┐
      │ Офіційні джерела обленерго (ранг 3)       │
      │ API, сайти, Telegram-канали; агрегатори — │
      │ лише резерв (ранг 1) і не перебивають     │
      └───────────────────────────────────────────┘
```

Пакет `GET /api/v1/sync` приходить одним запитом і містить усе для старту: статус мережі,
каталог областей, черги, графіки на сьогодні й завтра, режим мережі та останні новини. Він
кешується пʼять хвилин у памʼяті ізолята, Cache API та R2-знімку, тому й бот, і застосунки
читають той самий гарячий шлях, а D1 задіюється лише на побудову.

Офіційні джерела мають найвищий пріоритет: прямі API обленерго (наприклад,
`interruptions.energy.cn.ua` для Чернігівщини через Cloudflare Browser Rendering) і
`POST /internal/schedules-ingest` від колекторів на `curl_cffi` / `patchright`. Сторонні
агрегатори залишаються останнім резервом і ніколи не перезаписують офіційні дані.

## Стек

| Частина | Технології |
|---|---|
| Веб | React 19, Vite, Tailwind 4, TanStack Query 5, react-router 7, ECharts 6, Leaflet 1.9, i18next, `vite-plugin-pwa` |
| Android | Expo SDK 58, React Native 0.88, expo-router, NativeWind 4, Hermes, `@notifee/react-native`, Kotlin-модулі OTA та віджетів |
| Спільні пакети | TypeScript strict: `@svitlo/domain` (чистий домен без runtime-залежностей), `@svitlo/core` (API, сховище, UI-логіка), `@svitlo/shared` (контракти) |
| Прод-API | TypeScript, Cloudflare Workers, D1 (SQLite), R2, Cron Triggers |
| Локальний API | Fastify 5, PostgreSQL 16, Drizzle ORM (заморожений еталон) |
| Збір даних | Python (scrapling, curl_cffi, patchright) + Node ESM |
| Тести | Vitest (domain, core, web, mobile), `node --test` (cf-worker), pytest (правила публікації дня) |

## Структура репозиторію

```
apps/
  web/        PWA: екрани, графіки, закладки, пошук адреси, карта, Mini App
  mobile/     Expo/RN: застосунок, Kotlin-модулі OTA і віджетів, плагіни prebuild
  api/        Fastify 5 + PostgreSQL: локальний еталонний API (заморожений)
cf-worker/    Cloudflare Worker: /sync, інжест, бот, крон
packages/
  domain/     чистий домен: київський час, графіки, режим мережі, реєстр джерел
  core/       спільна логіка веб- і Android-клієнта
  shared/     контракти, каталог областей і аліаси дзеркал
ota/          підписані OTA-бандли та маніфест версій
tools/
  address-harvester/  збирачі офіційних довідників адрес
  noctalia-svitlo/    десктопний віджет і демон для Linux
docs/         архітектура, ADR, скріншоти
```

## Запуск

Потрібні Node.js 22+, pnpm 10+ і (для Android) JDK 17 + Android SDK/NDK.

```bash
pnpm install

# PWA: http://localhost:5173
pnpm --filter @svitlo/web dev
```

Веб за замовчуванням ходить у прод-API. Щоб підняти локальний Fastify + PostgreSQL:

```bash
docker run --name svitlo-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=svitlo -p 5432:5432 -d postgres:16

export DATABASE_URL=postgres://postgres:postgres@localhost:5432/svitlo
pnpm --filter @svitlo/api db:migrate
pnpm --filter @svitlo/api dev          # http://localhost:3001/api/v1/health
```

Android збирається через Expo prebuild і локальний Gradle:

```bash
pnpm --filter @svitlo/mobile prebuild
pnpm --filter @svitlo/mobile android
```

`expo prebuild` перегенеровує `apps/mobile/android`, тому нативні правки живуть лише в
`apps/mobile/native-android/` і `apps/mobile/plugins/`.

## Перевірки

```bash
pnpm --filter @svitlo/domain test
pnpm --filter @svitlo/core test
pnpm --filter @svitlo/web test
pnpm --filter @svitlo/mobile test
cd cf-worker && node --test tests/*.test.ts

pnpm check:boundaries      # правила залежностей між пакетами (ADR-0008)
pnpm gen:regions           # каталог регіонів мусить бути синхронний
```

## Обмеження, про які варто знати

- **APK лише `arm64-v8a`** (близько 21 МБ). Так зі збірки пішли бібліотеки для x86/x86_64 і
  32-бітних ARM; на інших пристроях застосунок не встановиться.
- **Частина областей приходить із дзеркал.** Якщо оператор не опублікував добу, застосунок каже
  «Немає даних» — це не «світло буде за графіком».
- **Повний стек із цього репозиторію не піднімається.** Прод-API, крон і збирачі живуть в
  окремому контурі; тут є клієнти, домен і локальний еталонний API.
- **Веб і Android — не одна кодова база.** Спільна логіка й контракти винесені в `packages/`,
  але UI-шари платформенні: DOM проти React Native.
